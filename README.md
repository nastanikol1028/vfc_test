# VFC-TEST

Текущая готовая версия сайта: https://vfc-test.indigoyew34.chatgpt.site

Адаптивный сайт на HTML, CSS и JavaScript. Главная, услуги, каталог из 12 категорий, одежда и текстиль, этапы работы, о компании, контакты и подбор документа. Карта с 50 городами, подсказками и пятью постоянными подписями; закреплённая шапка и анимации с учётом настройки уменьшения движения.

## Локальный запуск

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000. Сборка и установка зависимостей не требуются.

## Файлы

- `index.html` — общая разметка страницы.
- `style.css` — стили, адаптивная сетка и анимации.
- `app.js` — маршруты, страницы, поиск, вкладки, карта и формы.
- `assets/` — изображения, SVG и локальные шрифты Gilroy.

Формы подготавливают письмо на `m1@vfc-test.ru` в почтовой программе пользователя. Отправку подтверждает сам пользователь. Файлы можно прикрепить к письму перед отправкой.

В разделе «О нас» сохранены отмеченные заглушки для сведений о сотрудниках и этапах истории компании.

## GitHub Pages

Для публикации выберите ветку `main` и корень репозитория. Навигация использует адреса вида `#/services` и не требует серверных маршрутов.
