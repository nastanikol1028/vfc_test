# VFC-TEST

Корпоративный сайт услуг сертификации. Русский, английский и китайский языки; каталог из 12 категорий, формы Formspree, реестры и подбор документов.

## Запуск

Требуется Node.js 22 или новее.

```sh
npm ci
npm run dev
```

Открыть http://localhost:8773. Порт можно изменить переменной `PORT`.

```sh
npm run build         # исходники → dist, включая SEO-страницы
npm run preview       # просмотр уже собранного dist
npm test              # сборка, синтаксис JS, метаданные и внутренние ссылки
npm run format        # единое форматирование исходников
npm run format:check  # проверка форматирования
npm run test:browser  # Chromium: формы, меню, языки, опросник; preview должен работать
npm run test:regression # черновики, файлы, мобильная вёрстка, вкладки, контакты
```

## Структура

```text
src/
  index.html           HTML-каркас: шапка, подвал, глобальные диалоги
  manifest.json        порядок включения JS и CSS в сборку
  js/
    core/              маршрутизация, язык, SEO, доступность и навигация
    data/              тексты, услуги, категории, переводы, вопросы
    components/        общие элементы: формы, иконки, FAQ, обёртки страниц
    pages/             шаблоны страниц и разделов
    features/          формы, загрузки, поиск, реестры, помощник, анимации
    main.js            запуск приложения
  styles/              стили по разделам; порядок важен для CSS-каскада
public/assets/         изображения, SVG, шрифты и модель поиска
scripts/               сборка, проверка, локальный сервер
scripts/training/      исходные данные и обучение классификатора
public/                файлы, копируемые в dist без обработки
deploy/               конфигурация nginx
docs/                 технические пояснения и отчёт аудита
dist/                 результат сборки; не редактируется и не хранится в Git
```

Для `test:browser` нужен Chromium: по умолчанию `/usr/bin/chromium`, другой путь задаётся через `CHROMIUM_PATH`. Тест обращается к локальному серверу на порту 8773 и подменяет ответы Formspree.

JS остаётся обычным браузерным JavaScript, без перехода на фреймворк. Файлы используют общую область видимости и объединяются в порядке `src/manifest.json`; это сохраняет существующие зависимости. Это не ES-модули с `import/export`. Исходники разделены по назначению, а в браузер загружается один `app.js`. Подробнее: [архитектура](docs/ARCHITECTURE.md).

## Где менять содержимое

- Услуги: `src/js/data/services.js`, страницы — `src/js/pages/services.js`.
- Категории, регламенты, товары: `src/js/data/category-content.js`; SVG — `src/js/components/category-icons.js`.
- Партнёры и справочник: `src/js/data/knowledge.js`, `src/js/pages/knowledge.js`.
- Переводы: `src/js/data/translations.js`; переключение — `src/js/core/i18n.js`.
- Главная: `src/js/pages/home.js`; общие формы — `components/request-form.js` и `features/lead-forms.js`.
- Адрес сайта и SEO: `src/js/core/site-ux.js`. При смене домена обновить также URL в скриптах сборки/проверки и метаданные каркаса.

После изменений выполните `npm test`. Сборка создаёт HTML со сформированным контентом и метаданными, `sitemap.xml` и `robots.txt`. Старые ссылки `#/...` поддерживаются. Исходный каркас и данные — единственный источник для страниц; вручную дублировать HTML не нужно.

## Публикация

Docker собирает сайт в отдельном Node-слое, а затем nginx обслуживает только `dist`. Исходники, Node.js и зависимости в рабочий образ nginx не попадают. Для статического хостинга публикуйте содержимое `dist`. На Amvera используется существующий `amvera.yaml`.

См. [развёртывание](docs/DEPLOYMENT.md), [архитектуру](docs/ARCHITECTURE.md), [предыдущий аудит](docs/AUDIT_UX_SEO.md).

## Формы и внешние сервисы

Заявки передаются в Formspree. Адрес получателя, ограничения вложений и CAPTCHA настраиваются в кабинете сервиса. Публичный endpoint не является секретным ключом. Не отправляйте реальные тестовые заявки без согласования: в браузерных проверках ответ сервиса нужно подменять.

Отзывы загружаются с Яндекс Карт. Классификатор работает локально в браузере и помогает выбрать категорию, а не принимает юридическое решение о документах.
