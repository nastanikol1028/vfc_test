# VFC-TEST — сайт сертификации продукции

Адаптивный сайт на чистом HTML, CSS и JavaScript. Разделы открываются через навигацию и адресные маршруты в `index.html`.

## Запуск

Откройте `index.html` в браузере. Для публикации через GitHub Pages выберите ветку `main` и корень репозитория в настройках Pages.

Форма заявки подготавливает письмо на `info@vfc-test.ru` через почтовую программу пользователя; для отправки без неё потребуется подключить серверную обработку формы.
