# Размещение VFC-TEST на Amvera

Рабочая версия уже размещена: https://vfc-test.indigoyew34.chatgpt.site

Эта инструкция нужна, если вы захотите разместить отдельную копию на Amvera. Размещение на Amvera не выполнялось автоматически из этого репозитория.

## Что подготовлено

В корне есть `Dockerfile` и `amvera.yaml`, а в `deploy/` — `nginx.conf`. Контейнер отдаёт готовые файлы сайта на порту 80. Устанавливать Node.js, Python, базу данных и ключ ИИ-модели для запуска сайта не нужно.

## 1. Создайте приложение

1. Откройте https://cloud.amvera.ru/ и войдите в свой аккаунт.
2. Нажмите «Создать проект» и выберите тип «Приложение».
3. Укажите название, например `vfc-test`, и подходящий тариф.
4. Дойдите до загрузки кода. Используйте конфигурацию из репозитория: Dockerfile, `amvera.yaml`, порт 80.

Основание: [быстрый старт Amvera](https://docs.amvera.ru/applications/quick-start.html), [Docker на Amvera](https://docs.amvera.ru/applications/configuration/docker.html).

## 2. Отправьте код из GitHub

Этот способ требует установленного Git. На Windows команды можно выполнять в Git Bash, на macOS — в Терминале.

Склонируйте готовый репозиторий:

```sh
git clone https://github.com/nastanikol1028/vfc_test.git
cd vfc_test
```

В Amvera откройте приложение → «Репозиторий». Скопируйте адрес его Git-репозитория. Он начинается с `https://git.amvera.ru/`.

В следующей команде замените адрес в кавычках именно на скопированный URL:

```sh
git remote add amvera "URL_РЕПОЗИТОРИЯ_ИЗ_AMVERA"
git push amvera main:master
```

Если компьютер запросит авторизацию, используйте учётные данные Amvera. В исходном GitHub репозитории ветка называется `main`, а получателем здесь является `master` в Amvera. Поэтому команда содержит `main:master`.

Если папка уже была склонирована ранее, сначала выполните в ней `git pull origin main`. Если remote `amvera` уже добавлен, повторно добавлять его не нужно.

Официальная инструкция: [подключение существующего репозитория](https://docs.amvera.ru/applications/git/secondary-origin.html).

## 3. Дождитесь запуска

После отправки кода Amvera запускает сборку и развёртывание. Откройте логи сборки. Docker собирает образ Nginx и копирует в него HTML, CSS, JavaScript, фотографии, шрифты и файл обученной модели.

Если возникла ошибка, проверьте, что `Dockerfile`, `amvera.yaml`, `index.html` и остальные файлы находятся в корне проекта, а папка `assets` загружена целиком. Код не нужно вкладывать в дополнительную папку `vfc_test` внутри репозитория Amvera.

## 4. Получите HTTPS-ссылку

1. Откройте вкладку «Домены» приложения.
2. Нажмите «Добавить доменное имя».
3. Выберите HTTPS и «Бесплатный домен Амвера».
4. Дождитесь создания домена и выдачи сертификата.
5. Откройте адрес, который покажет Amvera.

Для своего домена выберите «Свой домен» и внесите у регистратора именно те DNS-записи, которые покажет Amvera. Инструкция для основного домена и поддомена различается.

Официальная инструкция: [домены и сетевое взаимодействие](https://docs.amvera.ru/applications/configuration/network.html).

## 5. Проверьте сайт

- Откройте главную и страницу `/#/catalog`.
- Введите «ваза»: должна появиться категория «Посуда и товары для дома».
- Переключите язык на English и 中文.
- Откройте «Помочь с документами?» и пройдите пять вопросов.
- Проверьте форму с фото. Фотографии включаются в скачиваемый файл письма `.eml`.

Заявки отправляются пользователем через почтовую программу на `m1@vfc-test.ru`. Прямая серверная отправка электронной почты в этом проекте не подключена.

## 6. Обновляйте сайт

После новых изменений в GitHub выполните в локальной папке проекта:

```sh
git pull origin main
git push amvera main:master
```

Для автоматического обновления из GitHub используйте вкладку «Репозиторий» в Amvera и настройте подключение GitHub к ветке `main` по [официальной инструкции](https://docs.amvera.ru/applications/git/webhooks.html). После настройки следующий push в GitHub инициирует обновление. Токен GitHub, если он потребуется в выбранном способе подключения, вводите в интерфейсе Amvera.
