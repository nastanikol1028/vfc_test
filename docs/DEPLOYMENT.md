# Развёртывание

## Docker / Amvera

```sh
docker build -t vfc-test .
docker run --rm -p 8080:80 vfc-test
```

Первый слой устанавливает закреплённые devDependencies и выполняет `npm run build`. Финальный слой содержит nginx и готовую статику. Порт контейнера — 80, проверка доступности — `/healthz`. HTTPS настраивает платформа или внешний прокси.

Для Amvera сохранены `amvera.yaml` и Dockerfile. Исходники изменяются в `src` и `public`; коммит в подключённую ветку запускает настроенный платформой процесс. Само наличие коммита не подтверждает состояние развёртывания в личном кабинете Amvera.

## Статический хостинг / Sites

Выполните `npm ci && npm test` и опубликуйте `dist`. В Sites сохраняется существующий project_id в `.openai/hosting.json`, static.directory — `dist`. Результат сборки для публикации должен соответствовать сохранённому коммиту.

Для нового домена обновите VFC_SITE_ORIGIN, адреса в build/check, метаданные каркаса. Canonical и sitemap должны указывать на единственный рабочий домен.

## Старые инструкции

`DEPLOY_AMVERA.md` и `PREVIOUS_PROJECT_NOTES.md` в этом каталоге сохранены как история предыдущей структуры. Команды и расположения файлов из них могут быть устаревшими. Для текущего процесса используйте этот документ и корневой README.
