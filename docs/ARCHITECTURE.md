# Архитектура

## Источники и результат

`src` содержит редактируемый код. `public` содержит статические файлы. `dist` полностью пересоздаётся командой `npm run build` и исключён из Git. Все файлы JS/CSS форматируются Prettier; зависимости зафиксированы в package-lock.json.

## Загрузка

`src/manifest.json` задаёт порядок файлов. Сборка объединяет JavaScript в `app.js`, CSS в `style.css` без перестановки правил. Общая область видимости сохранена намеренно: рефакторинг структуры не меняет контракт существующих функций и обработчиков. Функции `wire…` подключают поведение после отрисовки страницы. `main.js` выполняется последним.

Данные отделены от шаблонов там, где существовал самостоятельный набор данных. Некоторые шаблоны по-прежнему содержат тексты и SVG-разметку: полная миграция на компонентный фреймворк не проводилась. Старые альтернативные шаблоны вынесены в `pages/legacy-pages.js`; они сохранены для отдельного последующего разбора зависимостей.

## Статические страницы

`scripts/build.cjs` выполняет тот же браузерный код в изолированном JSDOM без сетевой загрузки ресурсов. Для каждого маршрута сохраняется HTML с контентом и уникальными метаданными. Анимации и наблюдатели при сборке отключены. В браузере обработчики и интерактивность подключаются при запуске приложения.

Сборка не отправляет формы и не загружает внешние виджеты. Список маршрутов берётся из данных приложения. Встроенный сервер и nginx возвращают страницу 404 для неизвестных адресов.

## Проверка

`npm test` проверяет сборку, синтаксис, метаданные и наличие файлов для внутренних ссылок во всех созданных HTML. Для проверки интерактивности используйте браузер: мобильное меню, язык, услуги, оба помощника, загрузку файлов и подменённый ответ Formspree. Скрипты сборки не заменяют браузерную проверку.

## Стили

Файлы разбиты по существующим смысловым блокам. Порядок сохранён, включая поздние уточнения CSS: объединение похожих селекторов без визуального сравнения может изменить каскад. Новые стили следует добавлять в соответствующий раздел и проверять на мобильном и широком экране.
