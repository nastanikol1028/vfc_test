# Обучение классификатора товаров

`product-training-data.json` содержит 1094 вручную составленных названия товаров на русском, английском и упрощённом китайском для 12 категорий каталога. Данные посетителей для обучения не используются.

`train-product-classifier.py` обучает TF-IDF-модель символьных n-грамм и слов с логистической регрессией. В браузере `product-classifier.js` выполняет ту же векторизацию и расчёт вероятностей по экспортированным весам.

```sh
python -m pip install -r scripts/training/requirements-training.txt
python scripts/training/train-product-classifier.py
```

Результат сохраняется в `public/assets/product-category-model.json`. `product-model-validation.json` содержит отчёт проверки и контрольные примеры. Разбиение для проверки отделяет 20% исходных примеров, стратифицированных по категории и языку. Финальная модель для сайта обучается на всех примерах.

Это небольшой классификатор каталога, с ограниченным словарём и возможностью отказаться от уверенного ответа. Он не является генеративной языковой моделью и не определяет обязательные документы или технические регламенты.

Прямая рекомендация показывается при вероятности не ниже 0.65 и отрыве от второго варианта не ниже 0.2. Более слабые результаты предлагаются как возможные варианты. При максимальной вероятности ниже 0.3 посетителю предлагается уточнить товар или обратиться к специалисту. Эти значения не гарантируют правильность результата для нового товара.

Запрос пользователя обрабатывается локально в браузере. Внешний API, сервер с Python и ключ модели для работы сайта не нужны.
